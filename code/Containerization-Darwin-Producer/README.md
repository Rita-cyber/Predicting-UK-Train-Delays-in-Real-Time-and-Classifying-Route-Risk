National Rail Open Data Python Example
======================================

This repository contains an Python 3 example of how to use the Darwin v16
messages from the National Rail Open Data platform, located at the following URL:

* https://opendata.nationalrail.co.uk/

To use this service, you will need to sign up for a free account and subscribe
to the 'Darwin' feed.

Configuration
-------------

Edit `darwin-kinesis-producer.py` and set the `USERNAME`, `PASSWORD`,
`HOSTNAME` and `HOSTPORT` variables to the values shown in 'Username', 'Password',
'Messaging host' and 'STOMP Port' on the 'My Feeds' page.

Leave `CLIENT_ID` set to socket.getfqdn()}-{uuid.uuid4().hex[:8] - socket.getfqdn()

Returns the fully qualified domain name (FQDN) of the machine running the code.

On your local machine, this might be something like my-laptop.local.

It helps identify which machine the connection is coming from.

uuid.uuid4().hex[:8]

Generates a random UUID4, converts it to a hex string, and takes the first 8 characters.

Ensures uniqueness so multiple clients from the same machine don’t collide.

Combined with -

The final CLIENT_ID looks like:

my-laptop.local-1a2b3c4d


Guarantees that every STOMP connection has a unique client ID, preventing Darwin Push Port from rejecting it due to duplicate subscription IDs.

The `HEARTBEAT_INTERVAL_MS` is set by default to 15 seconds (15,000ms) - this
should be sufficient for almost every application. Don't change it unless you
have a good reason to do so.

`RECONNECT_DELAY_SECS` will enforce a 15-second delay before exiting. This will
let you run the client in a loop, such as through a shell script, and protect
against you accidentally degrading the service for everyone by reconnecting far
too frequently.
copy the ppv16 folder.
Finally, install the required dependencies by running `pip install -r requirements.txt`.

Generating classes
------------------

The messages are produced in XML format, and a good way to consume them is by
using generated classes with [PyXB](https://pypi.org/project/PyXB/).

bash:
`pyxbgen --schema-root=ppv16 --module PPv16 rttiPPTSchema_v16.xsd`

----------------

1. Create an ECS Cluster

Go to the ECS console → Clusters → Create Cluster.

Choose Networking only (Fargate) for serverless.

Give it a name, e.g., darwin-cluster.

2. Create a Task Definition

Go to ECS → Task Definitions → Create new Task Definition → Fargate.

Configure:

Task memory & CPU (depends on load; e.g 2GB memory).

Container:

Name: darwin-kinesis-producer

Image: your ECR image URI, e.g., 123456789012.dkr.ecr.eu-west-1.amazonaws.com/darwin-kinesis-producer:latest

Port mappings: not needed if only outbound streaming.

Environment variables: set your DARWIN_USERNAME, DARWIN_PASSWORD, KINESIS_STREAM_NAME.

Logging: configure CloudWatch logs.

3. Run the Task

Go to ECS → Clusters → your cluster → Tasks → Run new Task.

Select:

Launch type: Fargate

Task definition: your newly created task definition

Cluster VPC & subnets

Security group allowing outbound access (so it can reach Darwin host & Kinesis)

Click Run Task.

4. Monitor

Check logs in CloudWatch (configured in task definition) to verify streaming is happening.
